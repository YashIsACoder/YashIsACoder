Research

Skipping the work

With Khoi Nguyen Nguyen, Trung Hieu Nguyen and Ting Bai, for COMP3821 at UNSW.

On a deterministic MDP, the best long-run average reward is the best cycle you can reach. We proved a test that lets Karp’s algorithm skip whole components without changing a single answer, then built a C++ library to measure it.

  • 136graphs, every solver agreeing on every answer
  • 0wrong skips out of 3,037
  • 411×faster than Howard’s method on graphs built to be hard for it
