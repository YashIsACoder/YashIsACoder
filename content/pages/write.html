Set up one-click publishing on this device

Publish commits your post to the site’s GitHub repository from this page, using a token only you have. You do this once per device.

  1. Open GitHub’s new fine-grained token page.
  2. Name it “Website editor”. Under Repository access choose Only select repositories, then YashIsACoder/YashIsACoder.
  3. Under Permissions, set Contents to Read and write. Leave everything else alone, then press Generate token.
  4. Paste it below and press Save token. It stays in this browser and is only ever sent to GitHub.
